# Changelog

All notable changes to HoleBridge are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Releases are made by a person publishing a release on GitHub for a `v<version>` tag. A draft does not count:
publish it. Publishing starts the release workflow (`.github/workflows/release.yml`), which builds the archives
and uploads them to that release. If the changelog has a `## [<version>]` section for the version, the section
replaces the notes written on GitHub; if it has none, the notes written on GitHub stay. Add the section in the
commit that the tag points at.
